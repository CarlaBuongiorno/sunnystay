# ☀️ SunnyStay

A full-stack accommodation booking platform built with FastAPI, React and PostgreSQL.

## About the project

SunnyStay is a portfolio project inspired by accommodation booking platforms. It allows users to discover accommodation, search for available stays and manage their reservations.

## Tech Stack

### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Alembic
- Pytest

### Frontend
- React
- JavaScript
- CSS Modules

### Tools
- Git
- GitHub
- VS Code

## Features
- Browse accommodation
- Search and filter accommodation
- View accommodation details
- User registration and authentication
- Make reservations
- Manage reservations
- Prevent double bookings
